## แผนแก้ไข

จากการตรวจสอบ preview ล่าสุด ระบบดึงข้อมูลร้านสำเร็จแล้วและมีร้าน `Test` แสดงขึ้นมา แต่ในเครื่องผู้ใช้ยังเห็น skeleton loading ค้างอยู่ จึงควรแก้ให้หน้าแรกไม่สามารถค้างที่สถานะโหลดได้อีก แม้คำขอฐานข้อมูลหรือ session จะช้า/ค้างในบางเครื่อง

## สิ่งที่จะทำ

1. **ปรับการโหลดร้านอาหารในหน้าแรก**
   - ครอบ query ร้านอาหารด้วย timeout
   - ใส่ `try/catch/finally` เพื่อให้ `setLoading(false)` ถูกเรียกเสมอ
   - ถ้าโหลดไม่สำเร็จ ให้แสดงข้อความ/ปุ่มลองใหม่ แทน skeleton ค้างถาวร

2. **เพิ่ม feedback เมื่อโหลดข้อมูลร้านผิดพลาด**
   - แสดง toast แจ้งว่าโหลดร้านไม่สำเร็จ
   - เก็บ state error เพื่อให้ผู้ใช้กด “ลองใหม่” ได้

3. **ปรับการโหลดที่อยู่ไม่ให้กระทบหน้าแรก**
   - ครอบ query ที่อยู่ด้วย timeout เช่นกัน
   - ถ้าโหลดที่อยู่ไม่สำเร็จ จะไม่ทำให้หน้าร้านอาหารค้าง

## ไฟล์ที่จะปรับ

- `src/routes/_app/home.tsx`

## ผลลัพธ์ที่คาดหวัง

- หน้าแรกจะไม่ค้างเป็น skeleton ถาวรอีก
- ถ้าข้อมูลร้านโหลดได้ จะเห็นร้านอาหารทันที
- ถ้าโหลดไม่ได้จริง จะเห็นข้อความผิดพลาดพร้อมปุ่มลองใหม่
- การบันทึก/โหลดที่อยู่จะไม่ทำให้รายการร้านอาหารค้าง
