
# แผนสร้างแอปส่งอาหาร (MVP)

## ภาพรวม

สร้าง **Responsive Web App** หนึ่งโปรเจกต์ที่รองรับผู้ใช้ 4 บทบาท (ลูกค้า / ร้านอาหาร / ไรเดอร์ / แอดมิน) ใช้งานบนมือถือได้ลื่นเหมือนแอป ติดตั้งลงหน้าจอได้ (PWA) ใช้ Lovable Cloud เป็นหลังบ้านครบทุกอย่าง

> หมายเหตุเรื่อง Android: Lovable build .apk เองไม่ได้ แต่เมื่อเว็บเสร็จและทดสอบลงตัว สามารถนำโค้ดไปห่อด้วย **Capacitor** ใน Android Studio เพื่อขึ้น Google Play ได้ (เป็น Phase 2 — นอก Lovable)

## ขอบเขต MVP (Phase 1)

โฟกัสที่ **สั่งอาหาร** เท่านั้น ยังไม่รวม "เรียกรถรับส่งผู้โดยสาร" (ค่อยเพิ่มใน Phase 3 เพราะ logic ต่างกันมาก)

## หน้าจอตามบทบาท

### 1. ลูกค้า
- สมัคร / ล็อกอิน (อีเมล + รหัสผ่าน)
- หน้าแรก: ค้นหาร้าน, หมวดหมู่อาหาร, ร้านใกล้ฉัน
- หน้าร้าน: ดูเมนู เลือกของ ใส่ตะกร้า
- ตะกร้า + checkout: เลือกที่อยู่ส่ง, สรุปราคา, วิธีชำระเงิน (เก็บปลายทาง / เงินสดก่อน)
- ติดตามออเดอร์: สถานะ realtime (รับออเดอร์ → ทำอาหาร → ไรเดอร์รับ → กำลังส่ง → ส่งสำเร็จ)
- ประวัติออเดอร์, ให้คะแนนร้าน/ไรเดอร์
- จัดการที่อยู่ส่งหลายที่

### 2. ร้านอาหาร
- ล็อกอินร้าน
- จัดการเมนู (เพิ่ม/แก้/ลบ, อัปโหลดรูป, ตั้งราคา, ของหมด)
- รับออเดอร์เข้าใหม่ (แจ้งเตือน + เสียง)
- กดยืนยัน → กำลังทำ → พร้อมส่ง
- ดูยอดขาย / ออเดอร์รายวัน
- เปิด/ปิดร้าน

### 3. ไรเดอร์
- ล็อกอินไรเดอร์
- เปิด/ปิดสถานะออนไลน์
- ดูออเดอร์ที่กระจายให้ (ระยะทาง + ค่ารอบ)
- กดรับงาน → ไปรับที่ร้าน → ส่งถึงลูกค้า
- ประวัติรอบ + รายได้

### 4. แอดมิน
- Dashboard: ออเดอร์รวม, ยอดขาย, ผู้ใช้, ไรเดอร์ออนไลน์
- จัดการร้าน (อนุมัติ/ระงับ)
- จัดการไรเดอร์ (อนุมัติ/ระงับ)
- จัดการลูกค้า
- ตั้งค่าค่าคอม / ค่าส่งพื้นฐาน

## ฐานข้อมูลหลัก (Lovable Cloud)

- `profiles` — ข้อมูลผู้ใช้ทั่วไป
- `user_roles` — บทบาท (customer / restaurant / rider / admin) — แยกตารางเพื่อความปลอดภัย
- `restaurants` — ร้าน, พิกัด, เปิด/ปิด, เจ้าของ
- `menu_items` — เมนูในร้าน
- `addresses` — ที่อยู่ส่งของลูกค้า
- `orders` — ออเดอร์, สถานะ, ยอดรวม, ลูกค้า, ร้าน, ไรเดอร์
- `order_items` — รายการในออเดอร์
- `riders` — ข้อมูลไรเดอร์, สถานะออนไลน์, พิกัดล่าสุด
- `reviews` — รีวิวร้าน/ไรเดอร์

ใช้ RLS policies เพื่อให้แต่ละบทบาทเห็นและแก้เฉพาะข้อมูลของตัวเอง

## เทคนิคที่จะใช้

- **TanStack Start (React)** — frontend
- **Lovable Cloud** — auth, database, storage รูปเมนู, realtime สถานะออเดอร์
- **Mapbox / Leaflet** — แสดงแผนที่, ตำแหน่งไรเดอร์ (ฟรี tier)
- **Tailwind + shadcn/ui** — UI สวย ตอบสนองทุกข
