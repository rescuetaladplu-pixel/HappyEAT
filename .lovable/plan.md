## เป้าหมาย
ปรับการ์ดภาพรวมร้านในหน้า `/my-restaurant` ให้อ่านง่ายขึ้น 3 จุด

## 1. แก้โลโก้ทับชื่อร้าน
ไฟล์: `src/routes/_app/my-restaurant.tsx`

ปัญหา: โลโก้ลอยขึ้น `-mt-10` แต่บล็อกชื่อร้าน (`Test` + แบดจ์ "อนุมัติแล้ว") ถูกดันมาชิดด้านล่างของโลโก้จนตัวอักษรซ้อนกับขอบล่างของโลโก้

แก้:
- เพิ่ม padding บน container ของชื่อร้าน หรือเปลี่ยน layout เป็น stack: โลโก้ลอยทับ cover ตามเดิม แต่ชื่อร้าน/แบดจ์/หมวดหมู่ ย้ายไปอยู่บรรทัดถัดไป (ไม่ใช้ `flex items-end` ที่ทำให้ baseline ชน)
- โครงใหม่: โลโก้ลอย `-mt-12` อยู่บรรทัดเดียว → ชื่อร้าน + แบดจ์ อยู่ด้านล่างถัดไป (`mt-3`) → หมวดหมู่ → คำอธิบาย

## 2. ปุ่มสวิตช์เปิด-ปิดร้านให้เด่นขึ้น พร้อมสถานะออนไลน์
ปัญหา: ตอนนี้สวิตช์เป็น pill เล็ก ๆ มุมขวาบนของ cover เห็นแค่คำว่า "เปิด"

แก้:
- ย้าย/เพิ่ม **แถบสถานะ** เป็นแถวแยกใต้ส่วนหัวการ์ด (เต็มความกว้าง) แทนที่จะซ่อนมุมบน cover
- ดีไซน์แถบ:
  - พื้นหลังสีเขียวอ่อน (`bg-green-500/10`) เมื่อออนไลน์ / สีเทาอ่อนเมื่อออฟไลน์
  - จุด ping เขียว + ข้อความตัวหนา: **"ออนไลน์ – พร้อมรับออเดอร์"** หรือ **"ออฟไลน์ – ปิดรับออเดอร์"**
  - `Switch` ขนาดมาตรฐาน อยู่ขวาสุด พร้อม label "เปิดร้าน"
- ยังคงสวิตช์เล็กบนมุม cover ไว้ก็ได้ หรือเอาออกเพื่อไม่ให้ซ้ำ → เลือกเอาออก เหลือแถบสถานะหลักอันเดียว

## 3. แสดงตารางเวลาเปิดร้านแบบสรุป
ปัญหา: ตอนนี้แสดงแค่ "วันนี้ 09:00 - 21:00" ผู้ใช้ไม่เห็นภาพรวมว่าตั้งค่าเปิดวันไหนบ้าง

แก้: เขียนฟังก์ชัน `summarizeOpeningHours(opening_hours)` ที่คืนข้อความสั้น ๆ:
- จัดกลุ่มวันที่มีเวลา open/close เหมือนกัน และไม่ closed
- กรณีที่ครอบคลุม:
  - ทุกวันเหมือนกัน → `"เปิดทุกวัน 09:00 - 21:00"`
  - จันทร์–ศุกร์เหมือนกัน + เสาร์อาทิตย์ปิด → `"เปิด จ.-ศ. 09:00 - 21:00"`
  - เปิดบางวัน เวลาเดียวกัน → `"เปิด จ., พ., ศ. 09:00 - 21:00"`
  - เวลาแตกต่างกันหลายช่วง → แสดงหลายบรรทัด เช่น `"จ.-ศ. 09:00-21:00"` / `"ส.-อา. 10:00-22:00"`
  - ปิดทุกวัน / ยังไม่ตั้งค่า → `"ยังไม่ได้ตั้งเวลาทำการ"` พร้อมลิงก์ไปหน้าตั้งค่า
- ใช้ตัวย่อ: จ. อ. พ. พฤ. ศ. ส. อา.
- แทนที่บรรทัด `todayLabel` เดิม + ลบบรรทัด `(วันนี้: ศุกร์)` ทิ้ง

## รายละเอียดทางเทคนิค
- ทั้งหมดเป็นการแก้ UI ใน `src/routes/_app/my-restaurant.tsx` ไฟล์เดียว
- ไม่แตะ schema / business logic / RLS
- `summarizeOpeningHours` เป็น pure function วางบนสุดของไฟล์ ใต้ `JS_DAY_TO_KEY`
- ใช้ semantic tokens สำหรับสีที่มีอยู่ (`bg-primary`, `text-muted-foreground` ฯลฯ); สำหรับสถานะออนไลน์ใช้คลาส green ที่ใช้อยู่แล้วในหน้า profile เพื่อความสม่ำเสมอ
