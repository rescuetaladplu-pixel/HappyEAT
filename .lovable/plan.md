## เป้าหมาย

ปรับหน้าแก้ไขที่อยู่จัดส่ง (sheet ในหน้า `/home`) ให้มีฟิลด์ครบสำหรับการจัดส่ง:
- ปักหมุดบนแผนที่ (เหมือนหน้าร้านอาหาร)
- ชื่อสถานที่ (มีอยู่แล้ว)
- ชื่อผู้รับ
- เบอร์ติดต่อหลัก (จำเป็น)
- เบอร์ติดต่อสำรอง
- โน้ตถึงไรเดอร์
- ที่อยู่ (มีอยู่แล้ว)

## สิ่งที่จะทำ

1. **Migration เพิ่มคอลัมน์ใน `addresses`**
   - `contact_name text`
   - `phone_primary text`
   - `phone_secondary text`
   - `rider_note text`
   - (`latitude`, `longitude` มีอยู่แล้ว)

2. **อัปเดต Sheet แก้ไขที่อยู่ใน `src/routes/_app/home.tsx`**
   - ใช้ `LocationPicker` ตัวเดียวกับหน้าร้านอาหาร พร้อมปุ่ม "ใช้ตำแหน่งปัจจุบัน"
   - เพิ่มช่อง: ชื่อผู้รับ, เบอร์หลัก *, เบอร์สำรอง, โน้ตถึงไรเดอร์
   - validate เบอร์หลักก่อน save (จำเป็น, รูปแบบเบอร์ไทย)
   - โหลดค่าจาก default address มาแสดง
   - upsert ลง `addresses` พร้อม lat/lng

3. **อัปเดตการสั่งซื้อใน `src/routes/_app/cart.tsx`**
   - ดึง address แบบเต็ม (รวมเบอร์/โน้ต) มาเป็นค่าเริ่มต้น
   - ส่ง `delivery_lat`, `delivery_lng` ลง `orders` ด้วย
   - แนบเบอร์ติดต่อ + โน้ตไรเดอร์ลงใน `notes` ของ order (ตาราง orders ไม่มีฟิลด์เบอร์ จึง concat ลง notes)

## ส่วนที่ไม่แตะ

- ไม่เปลี่ยน RLS ของ `addresses` (policy "Users manage own addresses" ครอบคลุมอยู่แล้ว)
- ไม่เพิ่มหน้า "จัดการที่อยู่หลายรายการ" ตอนนี้ ใช้ default address เดียว
